`requirement_description` is `<type>:<GROUP_ID>` and `requirement_group_id` is the item/product-line key the clause was extracted under (e.g. `product:SUBMERSIBLE_PUMP_01`). A group therefore holds every constraint of one line item, regardless of topic; it does NOT identify clauses of one standard (column `groups_sharing_one_standard_id` counts groups whose members all share one standard id). ### 8.2 Definitions

- **Standard id**: regex over `raw_text`, `buyer_value`, `requirement_description`; upper-case prefix IS|ISO|IEC|BIS|EN|ASTM|DIN|BS, optional `:`/space/`-`/`/`, 3-6 digits; `IS:8034` and `IS 8034` -> key `IS 8034` (year suffix and part numbers ignored). A constraint with several ids joins the id shared by most active constraints.
- **Group (primary)**: same key, >= 2 members, >= 1 HARD. **Sensitivity**: identical whitespace-normalised `raw_text` (one extracted sentence), >= 2 members, >= 1 HARD.
- **Merged cell** precedence: FAIL if any member FAIL; else PENDING_VERIFICATION if any member PASS or PENDING_VERIFICATION (a claim exists); else UNKNOWN. **Merged hardness**: HARD if any member HARD (so a SOFT FAIL member can become a HARD FAIL).
- **Classes** (mutually exclusive): excluded = >= 1 HARD FAIL; else hasU = >= 1 HARD UNKNOWN, sF = >= 1 SOFT FAIL: verified (not hasU, not sF), conditional (hasU, not sF), soft_only_blocked (not hasU, sF), conditional_and_soft_blocked (hasU, sF).
- **Eligible classes per variant**: V0 and V1: verified only (conditional is a would-be class, current rule blocks HARD UNKNOWN). V2 and V3: verified + conditional. UNKNOWN is never treated as PASS: conditional means *cannot be excluded, must be verified*.
- `negotiation_triggers_naturally` = eligible < min_shortlist (3) AND soft pool >= 1, where soft pool = soft_only_blocked (V0, V1) or soft_only_blocked + conditional_and_soft_blocked (V2, V3). `would_be` applies the literal formula (verified + conditional < min_shortlist AND soft_only + cond_and_soft >= 1) to every variant.
- V0 current; V1 = D046 only; V2 = D047 only; V3 = D046 + D047.
